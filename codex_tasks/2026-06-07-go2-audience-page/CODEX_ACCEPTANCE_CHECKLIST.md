# Acceptance checklist

Результат принят только если выполнены все пункты.

## Общий результат

- [ ] Медиакит содержит 4 страницы/секции.
- [ ] 4-я страница называется “Аудитория и рекламный потенциал”.
- [ ] 4-я страница визуально едина с первыми тремя.
- [ ] Первые 3 страницы не сломаны.
- [ ] Страница открывается как GitHub Pages static site без build step.
- [ ] Live URL обновлён: `https://ogelslamovuk.github.io/cl_mediakit/`.

## Визуальная стилистика

- [ ] Использован тот же Go2.by branding.
- [ ] Белый фон, тёмно-синий текст, лаймовый акцент сохранены.
- [ ] Карточки, радиусы, тени и отступы соответствуют текущему медиакиту.
- [ ] 4-я страница не выглядит как dashboard.
- [ ] 4-я страница не выглядит как скриншот Метрики.
- [ ] Вёрстка аккуратная и commercial-ready.

## Данные Метрики

- [ ] Указан источник: Яндекс.Метрика go2.by.
- [ ] Указан период: 01.03–30.04.2026.
- [ ] Использован KPI “до 100 тыс. визитов в месяц”.
- [ ] Формулировка “до 100 тыс.” подана как оценочный рекламный потенциал, а не как уникальные пользователи.
- [ ] География: 95%+ Беларусь.
- [ ] Устройства: 75% mobile.
- [ ] Возраст: 18–44 как активное ядро.
- [ ] Интересы: развлечения, финансы, спорт, транспорт.
- [ ] Пол: мужской сегмент 42%, без ложного утверждения о мужском большинстве.

## Betera relevance

- [ ] Есть отдельный акцентный блок “Почему это релевантно betting-партнёру”.
- [ ] Указан контекст развлечений и выбора досуга.
- [ ] Указан mobile-first сценарий.
- [ ] Указано пересечение с интересами спорт / финансы / развлечения.
- [ ] Формулировки выглядят профессионально, не как “натянутая статистика”.

## PDF / sync

- [ ] Проверено наличие PDF/source PDF.
- [ ] Если PDF доступен — обновлён до 4 страниц.
- [ ] Если PDF pipeline отсутствует — добавлен print-friendly путь генерации.
- [ ] HTML и PDF не расходятся по данным.

## Проверка

- [ ] Проверен desktop layout.
- [ ] Проверен mobile layout.
- [ ] Нет горизонтального скролла.
- [ ] GitHub Pages deploy успешен.
- [ ] Live URL проверен после deploy.
- [ ] Visual QA/artifacts предоставлены, если pipeline доступен.

## Финальный ответ Codex

- [ ] Указан branch.
- [ ] Указан commit.
- [ ] Указан PR.
- [ ] Указан deploy run.
- [ ] Указан live URL.
- [ ] Указано, что проверено.
- [ ] Указан список изменённых файлов.
- [ ] Указано, как синхронизирован PDF.
